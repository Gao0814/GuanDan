### 已解决：软信号没有候选排序载体（Step J-C2b1）

已完成：

验证：定向 120 项、全量 230 项测试通过；`git diff --check` 通过。

### P1：软排序尚无多样本改进证据

J-C2b2 只解决单样本指标定义，不能证明启发式有效。下一步需要：

- 用固定种子和确定性规则 AI 生成可重复对局；
- 在 `near_open_endgame` 与 `critical_endgame` 采集多个公开 observation；
- 运行 J-A 至 J-C2b2 的完整离线流水线；
- 仅由 `evaluation/` 读取真实手牌，并只输出聚合报告；
- 按阶段和总体聚合原始计数，重算指标而不是平均样本比率；
- 记录有效、无效、跳过样本及诊断频次；
- 在预先定义的门槛下决定保留、调整或撤销当前 pass 启发式。

### P1：RAG 不能单独承担策略路由

RAG 当前能找到相关经验，但文本命中不等于稳定策略选择。

合理顺序应为：

```text
统一阶段
  -> 公开局面分析
  -> 本地策略路由
  -> RAG 检索对应策略证据
  -> 本地策略或 DeepSeek 选择合法动作
```

### P1：没有策略质量基准

230 项测试证明当前实现满足已有功能契约，但不能证明：

- 公式开局提高胜率；
- RAG 改善动作质量；
- 记牌提高残局判断；
- 提示词变长带来实际收益。

## 6. 当前风险

1. 同时改阶段、猜牌、RAG 和策略会导致无法判断收益来源。
2. pass 是策略行为，不能作为“对方没有可压牌”的硬证据。
3. 单元测试和单样本报告不能证明启发式有效；必须先完成 J-C3a/J-C3b 的多种子聚合评测。
4. RAG 条目增加会扩大提示词，必须同步控制 token。
5. 当前没有 A/B 对局工具，策略增强暂时只能声明“已接入”，不能声明“已提升”。
