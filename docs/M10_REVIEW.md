## 实现核对

- `agents/bounded_continuation.py` 从完整公开 ledger、未见实体牌和各家容量生成至多两个可复现的可行分配，所有根动作共享分配。历史 pass 不形成硬排除，样本不进入 confirmed，也不表示真实概率。重复分配去重，不能按根结果补选有利场景。
- `engine/public_simulation.py` 只返回当前行动者的公开观察、合法动作和 step 结果。AI 不读取模拟内部状态；各行动者的续局策略只消费自己的公开 payload。重建核对实体守恒、本家手牌、公开历史及原始 canonical 根动作；后续合法性和结算复用引擎。

- 默认 Request 最多比较六条已展示的原始路线、两种公开策略、各八步。没有削减模型候选至推演根集合；未计算候选照常展示并明确不表示更差。新增信息位于候选段之前，模型成功后的返回路径没有改动。
- 指标来自实际轨迹：根后继续走牌、重新领牌、组牌领出、敌方夺本家牌权、初始紧迫敌方走牌及余牌资源。孤张点/成组点是按点数统计，不是最少手数；同花顺数是初始可用路线在余牌中的保留数。八步后未终局仍标未终局，只有引擎真正结束才报告项目规则胜/平/负，不补个人名次。场景/策略方向反转会提示分歧。
