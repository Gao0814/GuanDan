## 已核对事实与目标

固定 workspace 第 27 局 `games/2026_9_29_16-21-21_000027/` 末步由公开历史与 108 张守恒唯一确认：队友 3 已头游、对手 2 已二游、对手 4 单 6 领出后仅余级牌 `2C`，本家有 `44、99`。原始合法动作是两个不同实体单 9 ID 与 pass。模型等约 54 秒后选 pass；平台结果为本队胜。当前 `analyze_public_endgame` 给三个 ID 的 minimax 值均为 0（规则平）、无唯一保胜动作，因而未本地选择；`format_public_endgame_comparisons` 只在值不同时输出，实际请求重复展示两种普通单 9 与 pass 的关系，未直接提供确认的对手末张点数。规划用公开可重建引擎状态穷举这一步：任一 9 的可达结果包含 `[3,2,4,1]` 规则平和 `[3,2,1,4]` 本队胜，pass 只可达前者；对手用 `2C` 压 9 时仍是平。故“不能保胜”不等于“没有任何获胜续局”，三路保底相同也不代表机会相同；上述胜局依赖对手选择 pass，不是胜率预测。

目标是在**已公开确认且有界可求解的小残局**及时决策。用公开可还原的全部活动手牌和引擎规则，区分三个不同结论：双方最优回应下的保底结果、各条合法续局实际可达到的结果、动作之间的策略等价。完整搜索若证明某路线的保底不低于所有其他路线、可达最好结果严格更好，且不存在未计入项目终局目标的真实取舍，可在模型前选择该路线的原始合法 ID；唯一保胜路线、所有路线确定同一终局结果、或所有合法续局都无法获胜且存在确定的最优可达路线，也属于可证明的捷径。不能把“对手有办法令我输”的 minimax 值误写成“任何续局都不可能赢”，不能仅凭各动作 minimax 胜/平/负相同便任选，更不能把可达好结果解释为对手犯错概率。证明不足、搜索超限或存在实际策略取舍时，把可公开确认的外部末张/手牌（必要时保留花色）及有用的条件性比较明确传给 DeepSeek，而不是因为动作值相同就省略。不要给对手剩一张或某牌点加固定强制规则；成功模型原始合法 ID 仍保留。

所有者明确：仅当**本家当前整手牌连同逢人配可能性也不存在任何可形成的同花顺路线**时，普通同点数、无逢人配实体承载的动作不必仅因花色不同占用多个策略展示位；用可追溯的原始合法 ID 作代表。即使 `wildcard_count=0`，承载牌若含红桃级牌 `2H` 也不得被当作普通同点牌折叠。当前记牌器保留实体花色，故不能全局只按点数记牌：公开已出牌、本家未出牌和外部可行同花顺仍须使用真实 `carrier_cards` 花色；红桃级牌逢人配身份也不得抹去。不得改引擎 `legal_actions()` 的 canonical 展开、删原动作、伪造 action ID 或把具有不同通配/未来资源影响的动作误并。最终展示上限 80，推荐与关系双端闭环。
