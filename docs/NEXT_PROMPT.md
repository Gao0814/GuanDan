## 工作边界与实现判断

1. 复用既有提取/逐家应手机制，让只有一条非pass的跟牌局面也能输出对当前桌面与合法替代有决策价值的历史pass证据。不能依赖凑两条非pass、增加虚假候选或放宽动作解析。只选择相关且有界的证据；保留玩家、当时控桌归属、被让牌型/强度、当时余张、后续实体变化等实际需要的信息。队友/对手复用同一机制，仅角色与当前目标不同，不另建并行记牌器、跨局画像或全历史冗长提示。
2. 根据公开上下文区分普通策略pass与“只剩末手、对手控桌、若可接则能立即出完却pass”的强负向行为线索。后者应降低对其接牌收尾的依赖；无手牌变化且当前同型领出更强时，旧线索仍相关。普通pass保留无合适应手、保护组合、策略让牌等竞争解释；后来同型应手可证先前pass不等于缺牌，但仅凭行牌先后不能断定实际拆牌。复用已有confirmed_selective语义，结合可验证实体变化更新，缺历史/轮次不匹配/无法还原当时余张时降级，不补造。事实、行为假设与暗牌确证分别表达；强线索不等于硬排除。不要写无来源数值概率或把重复pass当独立样本叠加。
3. 核对并最小修正支援队友意图/应手表达与RAG的消费：队友余张少是本队目标，不证明其能接；对手控桌时，压对手也可能服务协同，不能把support_teammate默认为pass。让牌收益与本家低成本应手、对手续领代价共同比较。对手此前pass的解释同样结合其后续走势，用于是否争权/阻断的条件化比较，不能由不接小牌就断言其即将冲刺。相关经验按实际局面与行为证据消费，不能仅因队友余2张只留下泛化残局规划。允许最小调整路由或既有检索/表达接线，不靠无条件阻断、固定加分或堆重复攻略。
4. 必要时修正M10对照对行为证据的解释：规则可行假设不自动具有同等行为支持；若某假设与“能走即走”的所用策略下的历史末手pass不相称，显式区分，不能把它当公开确证或占比概率。不新增第二套猜牌系统、硬删规则可行世界或按本例强行重抽有利世界。如补即时清牌/队友收尾对照，应复用同一推进结果；根动作与根后进展口径明确，不增假设、深度、预算。数值正确不等于取舍改善。
5. 本轮先完成该行为证据闭环，不扩展成全局对手建模。B已列入顺序：条件化比较清小对与带中间对保留回手等解释，验证外部携带对子对当前应手的价值；现有本家候选梯度不能冒充他家余牌事实。B需A验收后单独明确机制/合法反例与模型对照，本轮不顺手开发。M9默认完成率/递归合法生成性能在B后继续，不同时重构搜索。
