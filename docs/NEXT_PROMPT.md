# 下一项 Coding 任务：M4 现场反例驱动的取舍输入修正

你是 Coding Codex。先读 `AGENTS.md`、适用项目 Skills、`docs/PROJECT_STATUS.md` 顶部、`docs/PLAN.md` 顶部、`docs/INVARIANTS.md`、`docs/CODING_BOUNDARY.md`、`docs/STRATEGY_SOURCE_AUDIT.md`，并检查 Git status/diff/HEAD。只提交自己产生的业务代码、测试及直接相关文件；不要混入规划文档或未知改动。所有真实 Botzone 页面与 connector 操作仍由所有者完成；本任务不启动它们，也不读取、迁移或改写两个现场 workspace 的证据，不读写 `.env`。

## 任务目标

针对四局人工试测暴露的三类具体取舍，在**一个工作包**中改善完整 canonical 候选到 DeepSeek 默认 Botzone factory 请求的模型前比较，而非拆成只做检查的小阶段。DeepSeek 仍是有取舍局面的主要决策者。不得在成功模型返回后按偏好强制改动作，不得按截图牌点、固定 seed、action ID 硬编码，也不得把单次模型选择或四局 1 胜 3 负解释成因果胜率。

现场事实与证据边界：第 2 局两张截图显示本家先打 `333QQ`，其后剩两张 3，说明原先五张 3 自然炸被拆且 QQ 被打掉；稍后本家用四张 7 加红桃 2 打五张 7 炸，出后剩 `33、8、10、K`。第 3 局队友单 4 而本家未用单 10、第 4 局跟对手单 5 时本家用 2 而非 8，来自所有者亲眼观察。固定批次仅有低敏逐局结果和阶段事件，不含逐动作牌谱、请求或模型理由；不能声称已确认现场模型的内部原因。规划构造的完整牌池近似状态有 112 原始/80 最终候选，自然四张 7 与通配五张 7 都进入最终候选，但旧关系不直接比较二者；近似状态 `333QQ` 未进入最终候选，不等于现场也缺席。

## 实施

1. 从 `agents/action_structure.py`、`agents/strategy_recommendation.py`、`agents/deepseek_client.py`、相关 RAG 条目和候选裁剪入口审查三类动作在完整合法集、推荐、最终最多 80 个候选、关系双端与实际请求中的路径。修正真实缺口：自然五炸被三带二拆到余对、携带较高对子与其他保存强组路线的公开成本；同点自然四炸和额外使用红桃 2 形成更长炸弹的强度收益与通配机会成本；队友单张时 pass/普通接牌、对手单张时低/高同型跟牌与保留控制牌的实际选择。只呈现公开可核验的出后结构、当前压制与行动顺序，不推断暗牌或未来必然牌权。
2. 在完整 canonical 候选上选真正相关的少量对照，确保重要两端原始 ID 都进最终请求后才写关系；现有推荐与其他关系仍闭环。遇到预算冲突可调整代表优先级，但最终候选仍不超过 80、保留牌型覆盖，不为单张现场例子牺牲常见其他牌型。来源 B/C 只按已审计适用条件进入 RAG；“三带二偏用小对”“保留炸弹/通配”是 C 级可撤回假设，不得提升为禁止高对或禁止用配的硬规则。本地开局直选范围和模型成功后原始合法 ID/source=`model` 契约保持。
3. 用 108 张实体牌守恒的引擎合法状态构造截图牌型的**近似复现**，分别验证 `333QQ` 的拆炸与 QQ 成本、四张 7 与四张 7 加红桃 2 的比较。再构造第 3/4 局的合法跟牌变体，核对 pass/单 10、单 8/单 2 的候选可见和公开牌权/资源文字。每类加有意义反例：急需更强五炸或一次出完时可以花配；队友控桌应 pass；公开紧迫对手可值得花 2，避免把人的偏好写死。对照须由一般结构规则在换点数/换席位变体继续成立，不能只匹配截图手牌。
4. 用默认 Botzone factory 的禁网 fake transport 检查完整 Request：B/C 来源条件、候选 ≤80、原始 ID、推荐和关系引用闭环、可见牌型、模型成功选择原样保留。对至少三类同状态的改前/改后请求做有限真实 `deepseek-flash` 比较，最多 8 次外部请求、0 重试；模型不可用时保留禁网结果并如实报告，不因等待配置阻断代码交付。逐状态报告原始/最终候选、关键关系是否两端可见、模型选牌及可证的资源/余组差异；模型仍选旧路线时说明输入已送达与未证实收益，不改为后置覆盖。不要持久化 prompt、模型自由文本、凭据或 URL。

## 验收与交付

- 运行相关定向测试、主规则回归；涉及公共 DeepSeek/记牌/RAG 路径时运行全量 `unittest`，如受环境阻断写明命令和原因。`git diff --check` 通过。报告真实请求数与零重试、任何范围内剩余风险、规划没有真实现场动作证据的界限；只暂存并提交本任务自有文件，最后报告 commit 与 Git status。
