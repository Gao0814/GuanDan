## 事实与目标

规划只读核对固定 workspace 第 22 局 `games/2026_9_29_14-09-31_000022/`：第五次本家动作在模型 `timeout` 后由 `deepseek_rule_fallback` 选择自然三连对 `778899`（原始合法 ID 64），出后 8、9 各留一张；同一合法列表还可自然出 `888999` 钢板（ID 65），出后余孤张/余组更少。该局本队获胜，不得称前者导致失败，也不能从隐藏牌推定后者必胜。当前 DeepSeek 失败路径调用冻结 `FrozenRuleBasedAIAgent`；其排序先偏好少通配、再多出牌，同张数时按牌型名称，故在这个局面选三连对。这是回退机制问题，不是成功模型主动选择。第 22 局首手 K 是独立的开局公式行为，不属于本任务修改范围。

目标：仅改善 **DeepSeek 无有效合法选择时**的回退，在剩余很短的响应预算内，从当前原始合法动作中选择，比较动作即时效果、出后余组/孤张、自然组牌拆分与控制/通配资源消耗。特别避免同张数、同通配成本的候选仅因牌型字符串排序而选出明显更破碎的余手。终局出完、公开对手紧急、队友控桌等反例可以改变结构偏好；结构事实不足或计算超预算须及时返回安全合法动作。尽量复用现有候选结构事实或其轻量等价机制，具体实现由代码调查决定。不要为了这局固定偏好钢板，也不要无条件追求最少孤张；DeepSeek 成功返回的合法原始 ID 不得后置改牌。不要修改历史冻结评测 selector 的语义，除非能证明它不是冻结契约且测试与评测均允许。
