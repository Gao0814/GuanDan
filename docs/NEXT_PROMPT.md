- pass是放弃当前应手、等待后续实际行动；后续是否有再次行动机会、能否压回及取得牌权均不保证。队友三张9带对子已经施加同型压制门槛；对手若接必须投入更高三张带对子或合法跨型资源来争牌权。若随后被本家合法压回，这些投入没有换到最终牌权，应作为协同路线的收益比较，不能只用“对手清了五张牌”淡化争牌权资源损失。具体资源相对价值仍按公开牌面判断，不预设对手持牌、反压必成或每种更高三带二都是最高控制资源；清牌、争牌权和本局名次分别衡量。
