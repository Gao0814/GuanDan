# 当前公开记牌与牌面信念

## 实际运行机制

公开输入仅包括本家手牌、其他玩家公开状态、history动作/finish_order及可选阶段信息；不能读其他玩家真实手牌或引擎内部状态。两副108张按实体token多重集计数，重复token表示不同副本。

`card_belief.py`已经逐家记录played_cards与pass_count，并输出未见token/点数牌池、公开剩余容量、relation及diagnostics。`card_constraints.py`按牌池/容量建立可能归属域；`card_allocations.py`在允许的小规模边界作有限可行分配。不存在把未知牌硬塞给一家或由pass排除能压牌的规则。

`card_tracker.py`从精确公开ledger重建事实、验证108张守恒与逐家已出+余张=27，输出行动顺序和候选相关应手/资源对照。完整历史中的pass机会与后来公开压牌仅是软证据，不改变硬牌域。原来的基本记牌和候选证据一直在用，不需要再造一个队友来源统计器。

历史真实消耗以carrier_cards为准；旧格式declared_cards回退只在兼容事实层降级使用，不能据此声称精确持牌归属或证据级。E0输入不足时省略推断；E1精确牌池但多人分配未知；E2仅在公开守恒与容量支持唯一归属时确证。

## 事实、假设与模型

- 公开事实：本家手牌、实体已出、公开余张及完赛顺序。
- 硬约束：实体守恒、玩家容量和完整逻辑唯一结论。
- 软信号：pass、首出/跟牌、拆牌等行为，可为策略性选择。

旧card_signals等公开事件工具已能按玩家汇总pass、首出/跟牌和牌型；并非本轮融合新增。均值或早炸频率不自动转成对手风格/未来概率，也没有独立收益证据。

confidence影子与prompt开关在DeepSeekAIAgent中默认false；旧confidence动作质量研究没有确认增益，默认关闭保持。通用牌面工具与必要回归覆盖保留，旧消融执行器按引用闭包退役；历史预注册门槛不约束普通开发。

M9只使用公开确证手牌和完整证明；M10用共同公开可行假设和实际引擎有界推进，截断结果不是终局。采样不进入confirmed，不代表真实概率或保胜；模型只在原始合法候选中取舍。

## 验证与维护

按实际修改选择牌池/容量/分配/pass证据及实际factory边界验证。ground truth仅供离线独立检查，不能进入运行时观察。异常或预算不足保留合法决策路径；不通过删失败测试掩盖错误。机制正确、模型真实选择和实战胜率是不同证据层级。

当前字段以实际dataclass和公开payload为准；旧J阶段逐轮报告、冻结资格与历史API实验在Git保留，不作为下一项任务。整体工程边界见AGENTS及INVARIANTS。
