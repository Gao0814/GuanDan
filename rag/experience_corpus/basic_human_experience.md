# 经验库使用边界

经验只能帮助比较已经给出的合法动作，不能生成动作或替代规则判断。局面证据不足、经验冲突或策略范围不匹配时，应把选择留给合法动作内的通用决策路径。

# 强控制开局的小单首攻

完成主攻、助攻或中性定位后，强控制牌可以用不拆已有组合的自然小单首攻，同时保留能够重新取得牌权的资源。局势变化时应重新评估，不把这一原则扩展成固定点数或花色偏好。

# 中性定位的开局表达

对子或三张首攻可以表达较中性的牌力定位，但这不是确定动作；仍需结合合法候选、手牌结构和随后局势决定。

# 弱牌开局的结构目标

弱牌组牌时可把减少总手数、改善牌型和减少孤张作为目标，但这些目标不推出“较高单张优先”等固定动作偏好。

# 残局按公开剩余信息规划

残局可结合各家公开剩余张数和本家的回手资源规划走牌；信息不足时这些只能作为参考，不能声称后续一定取得牌权或机械套用固定顺序。
